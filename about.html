What it is

The Memory Challenge is a nine-level visual number-position memory game created for the UAE children’s event project.

Game rule

Each level places numbered blocks in random positions on a 3×3 grid. The numbers are shown for a short memorization interval and then hidden.

show numbered positions → hide numbers → recall positions → tap 1, 2, 3… in order → advance

Progression

The number of active blocks equals the level number, from one block at Level 1 to all nine grid positions at Level 9. The memorization interval becomes shorter at higher levels.

A wrong tap removes one life and repeats the current level. Completing a level restores the run to three lives.

Event project context

This game belongs to the same kids-* set created for the UAE children’s event project.

Evidence boundary

The implemented mechanic exercises position recall and ordered tapping inside the game. The repository does not contain evidence measuring memory improvement or transfer outside the game.
