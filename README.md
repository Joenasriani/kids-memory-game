# The Memory Challenge

**Game lineage:** The Memory Game: Tap N# in Order  
**Repository:** `Joenasriani/kids-memory-game`  
**Status:** distinct browser game  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

The Memory Challenge is a browser memory game built around remembering and tapping numbered targets in the correct order.

This game is **not** the same lineage as Kids Memory Match. The similarly named repositories `kids-match`, `kids-svg`, and archived `kids-svg-game` belong to the separate matching-pairs game lineage.

Existing branches and historical files are retained as development history.
